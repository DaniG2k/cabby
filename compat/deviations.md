# Deviations from the Go reference

Cabby may improve on the Go implementation internally (algorithms, data structures,
concurrency). This file records only the changes that can be **observed from outside**
(wire format, defaults, limits, ordering, error codes, CLI output, timing contracts), plus
fixes to test tooling. Each entry links a test that pins the new behavior.

Internal changes that keep observable behavior identical don't need an entry. The
compatibility suite and the Go-vs-Rust benchmarks cover them.

The sections below separate entries by status:

- **Adopted: test tooling and upstream-compatible decisions**: fixes to the test tooling
  and harnesses, and decisions that keep Go's observable behavior (as a guarded invariant).
  The server behaves as Go does.
- **Implemented in Cabby**: observable differences from Go that Cabby implements today,
  each pinned by its test. The last column says how Go behaves in the same test.
- **Proposed (not implemented yet)**: changes under consideration, not in Cabby.
- **Resolved**: former deviations that no longer differ from Go.

## Resolved (no longer deviations)

- **D-017** (CLI fatal-error timestamp in UTC) and the UTC part of **D-028**: log times are now
  in the local time zone like Go's `time.Local`, read once from `TZ` or `/etc/localtime`
  (`cabby-core` `utils::localtime`).
